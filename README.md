# 襲色目あそび — かさねのいろめ

平安時代の貴族が衣の重ねで表現した色彩の組み合わせ「襲の色目」で遊べるWebアプリです。

🔗 **公開ページ**: https://neroli-labo.github.io/kasane-irome/

## あそびかた

| 間 | 内容 |
|----|------|
| 眺める（図鑑） | 春夏秋冬34種の襲を、袖口の重なりとともに一覧。札を押すといわれが開きます |
| 物語（古典） | 源氏物語・枕草子などの名場面17選。だれが・どんなときにまとった色かをかみ砕いて解説 |
| 当てる（遊び） | 袖口の色から襲の名を当てる五問勝負。成績で「位」が授かります |
| かさねる（誂え） | 伝統色24色から自由に重ねて自分の襲を仕立てると、似ている伝統の襲を見立てます |
| 今日（暦） | 三百六十五日、日替わりでおすすめの日本の伝統色をひとつ |

## 技術

- 単一HTMLファイル（依存なし・ビルド不要）
- フォント: Shippori Mincho B1 / Zen Kaku Gothic New（Google Fonts）

## おことわり

襲の色目は文献により諸説あります。本作は代表的な説をもとにした意訳・再現です。
古典の場面解説はかみ砕いた意訳、「今日の色」は季節にあわせた見立てです。
